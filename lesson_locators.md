# Homework Locators: XPATH и CSS

**Цель:**
Научиться уверенно находить элементы на странице с помощью CSS и XPath локаторов.

## Часть A. CSS и XPATH 
Пройти:
- Игра по CSS-селекторам: https://flukeout.github.io/
- Тренажёр по XPath: https://topswagcode.com/xpath/
- Выполнить все уровни в каждом тренажёре
- Сделать скриншот экрана, где видно, что уровни завершены
- Сохранить скриншоты в папку:

    locators/
      part_A/
        css_game_complete.png
        xpath_game_complete.png

## Часть B. Найти элементы на странице 
Перейти на сайт:
https://practice.expandtesting.com/xpath-css-tester
- Найти на странице элементы с помощью CSS и XPATH, которые показаны на изображении (в репозитории locators.png)

Для каждого элемента:
- Ввести локатор в поле на сайте
- Убедиться, что элемент подсветился (если элемент не подсвечивается — локатор неверный)
- Сделать скриншот страницы с подсветкой и локатором 
- Сохранить скриншоты в папку: 

    locators/
      part_B/
        element1_css.png
        element1_xpath.png
        element2_css.png
        element2_xpath.png
        ...

## Критерии оценки

Локаторы должны быть короткими, понятными и устойчивыми.
Хороший локатор:
- однозначно выделяет конкретный элемент (не 5 похожих)
- не зависит от динамических атрибутов (id="input_123abc" или сгенерированных классов)
- читается и понятен без комментариев
- максимально простой

**Пример плохих локаторов** 
```xpath
/html/body/div[1]/div[3]/form/input[2]      # абсолютный путь, ломается при изменении верстки
//button[contains(@class, "btn")]           # слишком общий
